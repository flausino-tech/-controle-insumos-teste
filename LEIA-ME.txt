================================================================
   COMO INSTALAR
================================================================

NO PC DO GESTOR
───────────────
1. Copie esta pasta inteira para o Desktop ou Documentos
2. Dê duplo clique em ABRIR_PILOTO.bat
   (requer Python ou Node — se não tiver, abre direto pelo arquivo)
3. Navegue: http://localhost:8080
4. Use:
      gestor.html      → para cadastrar/liberar OPs
      dashboard.html   → para acompanhar em tempo real
   Logins:
      Gestor:   usuário "gestor"    senha "1234"
      Operador: usuário "operador"  senha "1234"

NO TABLET (Samsung Galaxy Tab A9+ ou similar)
─────────────────────────────────────────────
1. Copie ESTA PASTA INTEIRA para o tablet (cabo USB)
   → recomendado: /Documentos/ELO DE VALOR
2. Abra "Meus Arquivos" no tablet → ELO DE VALOR → tablet.html
   Escolha Chrome (ou Samsung Internet) para abrir
3. No navegador, menu (⋮) → "Adicionar à tela inicial"
   Nomeie como "Operação"
4. SEGURANÇA — desative conectividade do tablet:
      • Retire o chip SIM
      • Configurações → Conexões → Wi-Fi → "Esquecer" todas as redes
      • Desligue Wi-Fi, Bluetooth, Hotspot
   Resultado: tablet só consegue acessar arquivos locais.
5. Configure "Fixar tela" do Android para travar no Chrome
   (busque "fixar" na busca das Configurações)
6. Operador usa o atalho "Operação" → PIN: 1234

================================================================
   WORKFLOW DE SINCRONIZAÇÃO PC ↔ TABLET (manual)
================================================================

Como o tablet está offline, a sincronização é feita por arquivo
JSON enviado entre PC e tablet (USB, OneDrive, e-mail).

ETAPA 1 — INÍCIO DE TURNO (PC → Tablet)
────────────────────────────────────────
   No PC:
   1. Abra gestor.html → cadastre as OPs do turno
   2. Clique "⚙ Gerenciar Dados"
   3. Clique em "📤 Selecionar OPs e enviar para o Tablet"
   4. Marque as OPs que o operador vai executar
      (já vêm marcadas as Liberadas + Em Execução por padrão)
   5. Clique "Gerar arquivo para o Tablet"
   6. Arquivo gerado: para_tablet_AAAAMMDD_HHMM.json

   Mande o arquivo para o tablet:
      • USB cabo → copie para /Download
      • Ou OneDrive / Google Drive / e-mail
      • Ou pen drive USB-C

   No tablet:
   1. Abra o atalho "Operação"
   2. Na tela de PIN, toque em "🔄 Sincronizar dados (gestor)"
   3. Digite a senha do gestor: 1234
   4. Selecione "Mesclar" (mantém OPs antigas que não estavam no arquivo)
   5. Escolha o arquivo recebido e clique "Importar"
   6. As OPs aparecem na lista do operador

ETAPA 2 — DURANTE O TURNO
──────────────────────────
   Operador trabalha normalmente no tablet:
      • Selecionar OP → painel operacional vivo
      • Cronômetro, apontamentos, granulometria multi-peneiras
      • Retirada de amostra, perdas, paradas (códigos oficiais)
      • Resolução de problemas (RCA) quando crítico
      • Tudo gravado localmente no tablet

ETAPA 3 — FIM DE TURNO (Tablet → PC)
─────────────────────────────────────
   No tablet:
   1. Na tela de PIN → "🔄 Sincronizar dados"
   2. Senha do gestor: 1234
   3. Clique "📤 Exportar tudo do tablet (JSON)"
   4. Arquivo gerado: tablet_export_AAAAMMDD_HHMM.json

   Mande o arquivo para o PC (USB, OneDrive, e-mail)

   No PC:
   1. Abra gestor.html → "⚙ Gerenciar Dados"
   2. Em "Importar", escolha o arquivo tablet_export_*.json
   3. As ações do operador entram no banco do PC
   4. Dashboard atualiza com os dados

OPCIONAL — LIMPAR TABLET
─────────────────────────
   Após confirmar que o PC recebeu, na sincronização do tablet
   você pode "Limpar todos os dados do tablet" (dupla confirmação).
   Isso evita acúmulo desnecessário entre turnos.

================================================================
   REGRAS DE MERGE (importação)
================================================================

Quando você importa um arquivo de OPs no tablet em modo MESCLAR:

   Se a OP NÃO existe no destino → adicionada
   Se a OP JÁ existe no destino  → vence a versão com atividade
                                     mais recente (último registro
                                     no histórico)
   Eventos                       → unidos e deduplicados por ID

Isso permite ida-e-volta sem perder dados, desde que ninguém
edite a MESMA OP no PC e no Tablet entre sincronizações.

================================================================
   FUNCIONALIDADES PRINCIPAIS DO TABLET
================================================================

   ✓ Login por PIN numérico (teclado on-screen)
   ✓ Auto-lock por inatividade (5 min) — exige PIN
   ✓ Botão "Travar" manual no header
   ✓ Bloqueios anti-tampering (context menu, F12, zoom, etc.)
   ✓ Modo tela cheia automático
   ✓ Cronômetro de produção fixo
   ✓ Granulometria multi-peneiras (Mesh 12/18/45/Fundo/Densidade)
     com avaliação automática pelo CATÁLOGO oficial:
        Fioccopan SIII, Milanês, Fioccogel, Crispy, Panko,
        Milanezin Milanês
   ✓ Alerta de granulometria obrigatória (bloqueante + som)
   ✓ Dispensa por senha do gestor (com registro de auditoria)
   ✓ Alerta de retirada de amostra (banner ciano + 1 beep)
   ✓ RCA (Resolução de Problemas) em 2 etapas:
        1) Senha do gestor
        2) Responsável + Setor + Causa + Solução
   ✓ Códigos oficiais de parada (17 da tabela RPRODa004)
   ✓ Sincronização manual com PC (importar + exportar + mesclar)

================================================================
   DADOS E PRIVACIDADE
================================================================

   Todos os dados ficam em localStorage no navegador local.
   Não há envio para nenhum servidor externo.
   O sistema funciona 100% offline (todos os arquivos locais).

   Para uma solução real com sincronização em tempo real,
   considere a evolução para arquitetura cliente-servidor
   (Backend REST API + Banco de Dados centralizado).
