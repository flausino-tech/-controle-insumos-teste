Informações do piloto

🔍 Como usar

  • Abra cada painel em uma aba separada no navegador
  • Use ABRIR_PILOTO.bat para melhor sincronização entre abas
  • Carregue dados demo no Gestor (⚙ Gerenciar Dados) para testar
  • Ative o toggle "1 min" no Operador para simular alertas de granulometria

🔒 Tecnologia

  • HTML5 + CSS3 + JavaScript puro — zero dependências externas
  • localStorage para persistência entre telas
  • StorageEvent para sincronização em tempo real
  • Polling de 5 s como fallback (file:// protocol)
  • Funciona 100% offline após abertura

📥 Exportação e Backup

  • Export geral em JSON (todas as OPs + eventos)
  • Import JSON para restaurar um backup
  • Export CSV compatível com Excel
  • Export de granulometria e OPs no Dashboard
  • Todos os dados ficam apenas neste navegador

⚡ Próximas evoluções

  • Backend API REST (Node.js / Python / .NET)
  • Banco de dados centralizado (PostgreSQL)
  • WebSocket para múltiplos tablets simultâneos
  • Autenticação JWT e perfis de usuário
  • Integração com ERP e relatórios PDF
